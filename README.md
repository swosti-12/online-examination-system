# EaseExam – Online Examination System

EaseExam is a web-based Online Examination System developed using PHP and MySQL.  
The project helps educational institutions conduct online exams efficiently while allowing students to attend exams digitally from a browser.

The system includes separate panels for administrators and students with features such as exam management, authentication, result generation, and database integration.


# 📌 Features

## 👨‍🎓 Student Features

- Student Registration
- Secure Login System
- Attend Online Exams
- View Exam Results
- User Dashboard
- Session Management

## 👨‍💼 Admin Features

- Admin Login
- Manage Students
- Create Exams
- Add Questions
- Manage Results
- Database Management
